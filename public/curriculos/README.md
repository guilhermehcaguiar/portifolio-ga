# Currículos de Guilherme Aguiar

Coloque aqui os PDFs finais com estes nomes exatos:

- Português: `guilherme-aguiar-pt-br.pdf`
- Inglês: `guilherme-aguiar-en.pdf`

O site mostra o botão de download somente se o arquivo do idioma estiver presente. Não há PDF fictício nem fallback para o idioma errado.

Depois de adicionar ou substituir os arquivos, reinicie `npm run dev` ou execute `npm run build` novamente antes de publicar. Os PDFs são detectados no servidor durante o build das páginas estáticas.

Tudo nesta pasta é público: confira os dados pessoais que deseja compartilhar antes de adicionar seus currículos. Esta instrução não substitui os PDFs.
